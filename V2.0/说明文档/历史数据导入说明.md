# 历史导入

保留V1.51的“导入Excel”按钮：可选文件夹或CSV/XLSX/XLSM/XLS文件，无需填写蓝牙或连接设备。每个设备/工作表独立重算，不擅自拼接跨文件记录。

历史处理使用与实时相同SecondBucket、SensorEngine和图表生成器，只是取消现实时间等待，按原时间戳顺序加速计算。原有滤波/baseline/响应/识别结果不被信任；只输入原始ADC、电阻、气压、温湿度，标签与动作只注释。缺气压不能用标签补开门；不满足a/b范围的事件不分类。

输出在experiment_data/设备号/开始_至_结束_history/，再导入加序号不覆盖；原始文件不修改。每组完成自动弹出可缩放的五图总览，可切换设备。支持取消任务，已完成结果保留。

请包含首次开门前至少90分钟的原始空仓记录，并保留末次开门后至少60分钟。大文件耗时随数据规模和电脑性能变化；交付验收包含长记录测速，5分钟是目标而非任意文件的保证。
