# HX4_V2.0测试操作指南

HX4_V2.0 测试人员操作说明

1. Windows 10/11 64位：把ZIP完整解压到可写文件夹，双击HX4_V2.0.exe。config文件夹必须和EXE保持同级，不要在ZIP内部运行。
2. 填写设备号、选择或手填测试环境、扫描并选择蓝牙，再连接BLE。设备号与蓝牙名称独立。
3. 首次操作前务必维持空仓至少90分钟，并从连接后的初始空仓阶段点击“开始保存”。软件不设置90分钟倒计时或强制门槛；这是测试人员必须遵守的实验条件。
4. 在每次开门取放物品时，及时通过“动作”记录“放入/拿出+具体物品”。标签只供记录，不参与自动分类。一次实验内不要混放。
5. 检测到开门后，识别框显示“识别中”；满60分钟且判别点齐全后出一次空仓/肉类/水果结果，保持到下次开门。请让两次开门间隔超过60分钟，建议留足余量，不要在等待期间反复开门。
6. 取点：气压确认开门-4秒为参考，前30分钟为a，后60分钟为b；每通道D=100*(b-a)/a。按|D|选最大通道，保留正负号为S。不平均，不算相邻S差值。
7. 分类：上次有效判断非空仓且S严格变号时优先判空仓；否则S<-24%水果，-24%<=S<-3%肉类，-3%<=S<5%空仓，S>=5%肉类（含鱼肉）。这些是候选实验阈值，不代表所有食材均已验证。
8. “结束保存”生成CSV、JSON、CH0/CH1/CH2原始电阻图、温湿度图、气压图和五图总览，共8个文件。路径为EXE旁experiment_data/设备号/开始_至_结束/。
9. CSV从点击开始保存立即创建，每个有效秒逐行写入并刷新落盘。无效传感器行跳过，实际时间保留，环境缺测留空。JSON从开始保存也存在，结束时补全事件详情和图表信息。
10. 历史数据无需蓝牙：点“导入Excel”，可选择CSV/XLSX/XLS/XLSM文件或文件夹；后台加速用完全相同的V2.0算法重算，完成后自动弹出五图总览。结果存到experiment_data对应设备下，文件夹以_history结尾，重复导入不覆盖。
11. 历史源文件必须有采集时间及CH0-CH2的ADC和原始电阻。旧滤波、baseline、resp和旧识别结果一律不作为输入；人工标签和标记只用于图与CSV注释。
12. 缺少气压不能检测开门，不用人工取放标签假造自动事件。检测事件的a或b在目标±2秒内没有有效数据时，继续显示“识别中”，详情提示缺点，不用更晚的数据替代。
13. 等待期间再次开门取消旧轮次，重新等60分钟；被打断或缺点的轮次会切断前次状态的异号参考，下一次完整轮次只按本次S阈值判别。
14. 参数在config/algorithm_v20.json恰好10项；也可点击“参数”编辑并保存到同一JSON。新值重新连接或下次历史导入生效，当前会话不热切换。
15. 原来的900秒等待、30有效点平均、滤波、动态baseline、alpha、趋势窗口和|resp|分类全部取消。全程曲线窗口改为三路原始电阻。V1.5依赖旧响应字段的120点ML自动采样不在V2.0中运行。
16. 退出或断开前优先点结束保存。断开会结束当前会话，重新连接按新的初始空仓实验开始，不能当作自动恢复上次已知状态。
