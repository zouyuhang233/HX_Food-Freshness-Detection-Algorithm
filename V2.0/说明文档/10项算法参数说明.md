# HX4_V2.0：10项算法配置

唯一配置文件为`config/algorithm_v20.json`。参数窗口和外部JSON编辑同源；会话启动读取快照，当前采集不中途切换。

| 参数 | 默认值 | 含义 |
|---|---|---|
| `pressure_window_s` | 8.0 | 气压比较窗口，秒。 |
| `open_rise_hpa` | 30.0 | 开门升压阈值，hPa。 |
| `opening_backshift_seconds` | 4.0 | 确认开门后往前移的秒数，取点参考t0。 |
| `reference_before_seconds` | 1800.0 | t0往前取a的秒数。 |
| `decision_after_seconds` | 3600.0 | t0往后取b的秒数；同时从实际确认开门起等待这么久再发布结果。 |
| `channels` | [0, 1, 2] | 当前固定CH0、CH1、CH2，三个通道分别计算。 |
| `operation` | "signed_abs_max" | 选|D|最大的通道并保留该D的正负号，绝不取三通道平均。 |
| `fruit_negative_threshold_pct` | -24.0 | S低于此值判水果，单位%。 |
| `meat_negative_threshold_pct` | -3.0 | 负向肉类与空仓边界，单位%。 |
| `meat_positive_threshold_pct` | 5.0 | S达到此值判肉类，单位%。 |

这10项为8项数值加2项结构设置。初始空仓至少90分钟是实验操作要求，不是参数，也没有软件学习门槛。

默认td为气压确认时刻，t0=td-4秒，a时刻=td-1804秒，b时刻=td+3596秒，发布结果在td+3600秒。改变前移量或前后时间会改变特征分布，不能默认旧阈值仍适用。

固定的可靠性实现规则单独说明，不属于10项调参配置：气压3秒因果中位数、1秒确认、超过5秒缺测清除短期历史、比较锚点2秒容差、气压有效范围100至1200hPa；电阻点取目标±2秒最近有效实测值，等距选较早点，不插值。缺点不由更晚样本代替。

没有电阻滤波、baseline、alpha、趋势、900秒等待、30有效点平均、相邻S差值或拒判带。三通道D=100*(b-a)/a；S保留胜出通道的符号。前次有效非空仓且S严格变号优先空仓，其余统一阈值。S=0不算异号。中断/缺点事件断开异号参考。

阈值是探索性候选，开门升压或周期相位变化仍可能与食材响应重叠，未证明对所有食材和设备稳定泛化。

## D与S的含义

D是单路变化率：D_i=100*(b_i-a_i)/a_i，负数表示后电阻较低，正数表示后电阻较高；共有D0、D1、D2。S取三路中|D|最大的一路，保留其符号，用于统一阈值与前次变号规则。例如D为-10%、-16%、+8%，S=-16%，胜出CH1。图中只展示S，三图的S相同；三路D只在内部计算和JSON保存，不在图上展示。
