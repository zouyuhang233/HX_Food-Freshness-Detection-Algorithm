# 数据与文件

CSV列：标签、设备号、环境、序列号、采集时间、温度、湿度、气压、ADC值_CH0/CH1/CH2、原始电阻_CH0/CH1/CH2、放入、拿出、识别结果。

CH3仍按四路协议接收，但不展示、不判别、不导出。RAW为板载电阻寄存器值，不是ADC，不重复做ADC转电阻。气压hPa，温度℃，湿度%RH。秒内有多次读数时沿用V1.51完成秒中位聚合；没有额外电阻平滑滤波。实际采样时间保留，跳过ADC或原始电阻无效行，不补零或造满秒。环境缺测留空。

CSV“识别结果”对应当时界面：空仓、识别中、肉类、水果；无法连接/断开属于会话状态。人工标签仍为具体食材，不作为分类器输入。

点击开始保存立即创建“开始_保存中_唯一号”文件夹，逐有效行flush并fsync。结束改名为“开始_至_结束”；8个交付文件为1CSV+1JSON+5单图+1纵向总览。中断尽力完成当前文件，硬崩溃保留已刷盘CSV和录制中JSON。

JSON记录10项会话参数、采集设置、开门检测时间、前移参考时刻、a/b目标和实际取点时间、电阻、采样序号、三通道D、胜出通道、S、判别依据及结果发布时间。每轮状态含waiting/completed/cancelled/missing_endpoint。记录事件可能早于本段开始保存，以解释段内判别参考；CSV仍只含保存范围。JSON不重复逐秒标签、电阻、温湿度。

图中只画原始电阻，标注有效a/b、S和识别结果；不画气压确认/参考时刻虚线，也不写开门编号文字，并保留人工取放文字。目标点缺测不画虚构点。a在保存范围外时JSON仍有点数值，图不延长、插值或造数据。

保存目录在源码run.py或EXE同级experiment_data/设备号/实验时间段/。完整采集缓存位于程序缓存目录，主图最多保留3600点；算法独立缓存所需开门前电阻，开始/结束保存不重置识别状态。

旧的baseline、滤波电阻、响应、ML_test_data自动窗口不再产生；如需沿用V1.5的旧机器学习采样，请运行保留的V1.51，不要把V2.0原始电阻比值冒充旧响应。
